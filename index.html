About Me

Delivering value through clean code & solid design

I am a Computer Science student at COMSATS University with hands-on experience engineering web systems. My expertise covers building responsive frontends in React and Tailwind CSS, supported by backend services in Python (FastAPI/Flask) and Node.js.

During my Full Stack Web Development internship at WebTech.dev, I started out learning the basics of React, Tailwind CSS, and Python, then moved on to building things on my own — designing a PostgreSQL database, building a FastAPI backend, and setting up secure JWT authentication.

I also built an OCR-based document processing pipeline and added an AI chatbot powered by Google's Gemini model, using RAG (Retrieval-Augmented Generation) so it could actually pull answers from uploaded documents. This project also became my Final Year Project, and by the end I'd shipped a fully working, AI-powered application — which gave me a lot more confidence in my abilities as a developer.
